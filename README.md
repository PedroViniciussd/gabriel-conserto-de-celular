# Gabriel Tech Elite - Site Next.js

Site institucional/landing page para assistência técnica em celulares, com foco em SEO local para Goiânia - GO.

## Tecnologias

- Next.js
- React
- Tailwind CSS via CDN
- HTML semântico
- SEO local com metadata e JSON-LD

## Como rodar

```bash
npm install
npm run dev
```

Acesse: http://localhost:3000

## Onde editar

- Conteúdo principal: `app/page.js`
- SEO/meta tags: `app/layout.js`
- Estilos extras: `app/globals.css`
- Imagens: `public/assets`
